# Open Source at KovacTech

## Get Involved

The KovacTech community is building modern software, tools, and platforms together. Contributors, testers, and developers are welcome — there are great **good first issue** opportunities across our repositories.

- Explore KovacTech projects and experimental labs
- Contribute features, fixes, and improvements
- Review open issues and discussions in each repository
- Use repository issues for project-specific questions and bug reports (instead of direct email)

Learn more about our ecosystem and technology at: **https://kovactech.com**

---

## Code of Conduct

All KovacTech projects follow the **KovacTech Open Source Code of Conduct**.

Please collaborate respectfully and professionally. By contributing, you agree to maintain a constructive and inclusive environment across all repositories.
